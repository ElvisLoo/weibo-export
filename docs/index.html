为什么选极客港微博导出

专注做一件事：把你自己的微博安全、完整地备份到本地

📄

五种格式导出

HTML 可在浏览器查看、Markdown 方便编辑、PDF 适合打印、JSON 方便程序处理、TXT 纯文本轻量。

🖼️

图片离线保存

自动下载全部配图到 media/ 文件夹，断网也能完整查看每条微博的图片内容。

📝

长博文全文展开

自动识别超长微博，调用全文接口拿到完整正文，不遗漏一个字。

🕐

导出内容严格从新到旧排列，兼容微博英文时间格式，不会乱序。

三步完成备份

1

下载解压

从 GitHub Releases 下载最新版，解压后整个文件夹放在一起，双击 exe 运行。

2

登录获取 Cookie

点击「登录取 Cookie」，在弹出的浏览器窗口登录微博账号，工具自动填入 Cookie。

3

抓取并导出

输入要备份的用户 ID，点「开始抓取」，完成后选格式点「导出」，文件就保存在本机导出目录。

常见问题

导出数量比微博主页显示的少？

主页总数包含已删除的微博，受限内容（仅自己可见、定时公开）也抓不全，这是正常的。

支持 Mac / Linux 吗？

目前只提供 Windows x64 版本。源码完全开放，Mac/Linux 用户可以自行从源码运行。

会泄露我的 Cookie 吗？

不会。Cookie 只存在你自己电脑上，工具不做任何上传或转发，源码开放可自行验证。

大 V 有几万条微博，一次能抓完吗？

可以，支持断点续传。如果中途中断，下次打开工具会自动从上次进度继续，不会重复抓。

这个工具免费吗？

完全免费，开源。基于 MIT 许可证，欢迎个人使用，商用请联系极客港。
