# v1.3.12 · 新增视频下载

## 核心变化：导出时把微博视频一起下载下来

之前只下图片、不下视频，很多真实表达都在视频里。这次补上：

- **视频随导出自动下载**：导出 HTML / Markdown / TXT 时，把博文里的视频（mp4）下载到该用户文件夹的 `media/`，和图片放一起。
- **HTML 里直接播放**：视频渲染成 `<video>` 标签，导出的网页能离线点开播放，不用再跳回微博。
- **Markdown 里给视频链接**：MD 里以 `[🎬 视频](media/xxx.mp4)` 形式引用本地视频。
- **JSON 里带视频字段**：JSON 导出显式加 `video_url`（远程原始链接），方便二次处理。

## 技术说明（如实）

- **视频来源**：从微博 `page_info.media_info` 提取。优先取 `playback_list` 里清晰度最高的 mp4，其次 `mp4_hd_url` / `mp4_url`。
- **只下 mp4，不下 HLS**：部分高清视频是 HLS（.m3u8 分片流），合并分片需要 ffmpeg。当前打包环境没有 ffmpeg，所以遇到 HLS 视频会跳过本地下载、回退为远程链接（HTML 里仍可点开在线看）。这是当前环境的限制，不是 bug。
- **下载失败优雅回退**：单个视频下载失败不中断导出，HTML/MD 回退为远程链接。

## 验证情况

新增离线测试 `test_video.py`，覆盖视频提取、去重收集、下载落盘、路径解析、HTML 渲染 5 个环节，全部通过。现有测试（长文补全、重试、链接解析、空页判定）也全部通过，未破坏原有功能。

真实联网下载未在本机验证（无有效 Cookie），需你下载后用带视频的微博账号实际导出确认。
