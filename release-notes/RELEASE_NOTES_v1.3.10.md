# v1.3.10 · 新增「补全长文」功能

## 这版做了什么

**新增「补全长文」按钮**——一键补全历史抓取数据里被截断的长博文，无需重新抓几百条。

## 背景

v1.3.9 修复了长文展开的 bug（字段名写错导致长博文从没展开过）。但**全文展开是在抓取阶段完成的**，导出只是读库。所以用 v1.3.7 及更早版本抓的数据，库里存的仍是截断版（末尾带「全文」链接），重新导出也还是截断的。

之前唯一的办法是重新抓全部博文。这版加了「补全长文」功能：**只扫库里已截断的长博文，逐条调全文接口补全**，几分钟搞定，不用重抓几百条。

## 怎么用

1. 输入用户 ID
2. 确保已填 Cookie（需登录态才能调全文接口）
3. 点「补全长文」按钮
4. 等进度条跑完，弹窗显示补全了几条
5. 点「导出文件」重新导出 → 长博文即为完整正文

## 技术细节

- `crawler.fill_longtext()`：扫描 raw 里 `isLongText/isLong` 为真、或正文末尾带「全文」的记录，逐条调全文接口
- `db.update_post_text()`：只更新 `text`/`text_raw` 两列，不误覆盖已抓到的计数、图片、raw 等字段
- 温和限速（每条间隔 1 秒），避免连续请求触发风控
- 进度条实时显示 `已处理/总数`，补全过程可见

## ⬇️ 下载使用

下载 `weibo-export-v1.3.10-win64.zip` → 解压 → 进入 `极客港微博导出` 文件夹 →
运行里面的 `极客港微博导出.exe`。

> 注意：exe 和 `_internal` 文件夹必须放在一起，解压后整个文件夹一起用。
