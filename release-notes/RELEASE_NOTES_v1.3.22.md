# 极客港 · 微博导出 v1.3.22

## 更新内容

### 网页版（服务器部署）
- **导出目录支持环境变量 `EXPORT_DIR`**：服务器部署时可自定义导出路径
  （如宝塔常见路径 `/www/wwwroot/weibo-export/微博导出`），无需再去找 `~` 家目录
- 环境变量路径不可写时**安全回退**到默认逻辑，避免服务启动失败
- 桌面端默认逻辑不变（`D:\微博导出`，无 D 盘回退到文档目录）

## 下载

- `weibo-export-v1.3.22-win64.zip`：Windows x64 单目录版，解压后运行 `极客港微博导出.exe`

## 说明

- 仅限个人备份自己有权访问的微博内容，请勿商用
- 服务器部署配置见仓库 `deploy/` 目录
