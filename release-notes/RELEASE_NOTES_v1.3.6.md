## 这版做了什么

**修复图标黑角 + 登录取 Cookie 的两个真 bug + 抓取空页误判。**

## 1️⃣ 图标黑角（彻底修复）

顶部品牌区那个橙色圆角 logo，之前四个角会露出黑色方块——因为图标 ICO 文件里
圆角外那圈是**纯黑且不透明**的像素，在浅灰背景上就露出来了。

这版把圆角外的黑角切成**透明**（不是涂成固定颜色）。透明比"改成和背景同色"更
彻底：品牌区浅灰、任务栏、桌面、标题栏背景各不相同，固定色换个背景还会露角，
透明则在任何背景下都不露黑角。

## 2️⃣ 登录取 Cookie：没登录也"抓到 cookie"（修复）

之前点"登录取 Cookie"，判断是否登录成功的条件是——cookie 里**只要出现
`SUB`/`SUBP`** 就算登录成功。

但微博在**未登录的游客态也会种下 `SUB`/`SUBP`**（那只是游客标识，不是登录凭证）。
结果就是：你压根没登录，它也探测到 `SUB` 就当成"登录成功"，抓了游客 cookie 回填，
GUI 还显示"✅ 已自动获取登录 Cookie"。

这版判定加严：**必须出现 `SSOLoginState` 或 `MLOGIN`** 才算真登录（这两个字段只有
真正登录了才有，游客态没有）。没登录点按钮会明确提示"这是游客标识，请先登录"，
**不再写入假 cookie**。

## 3️⃣ 登录窗口还没反应过来就消失（修复）

之前探测到（哪怕是误判的游客态）就自动抓取 → 立刻销毁窗口，全程不到一秒，根本
没机会在窗口里登录。

这版**去掉自动关窗**：探测到真登录后，只把底部按钮变绿提示"已登录，点此确认取
Cookie"，不再自动抓取、不再销毁窗口。取 cookie、关窗完全由你决定。

**正常流程**：点"登录取 Cookie" → 在窗口里登录微博 → 登录成功按钮自动变绿 →
点一下确认 → 回填主程序。

## 4️⃣ 抓取只抓到 10 条就"判定到底"（修复）

之前抓取时只要"连续两页空"就判定"到底了"。但第 2 页返回空，可能是**被限流**，
不是真到底——结果刚抓几条就停了。

这版区分两种空页：
- `ok=1` 且确实无数据 → 连续 3 页才判"到底"（真到底）
- 疑似限流 / 解析失败 → **退避后重试同一页**（最多 5 次），不再误判成到底，断点保留可续传

## ✅ 自测结果

- 抓取空页处理测试 3/3 通过
- 既有回归 16/16 通过
- GUI 实测正常，logo 无黑角、版本号 v1.3.6
