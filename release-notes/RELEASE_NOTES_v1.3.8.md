# v1.3.8 · 修复 HTML/MD 导出内容时间乱序

## 问题

导出的 HTML/MD 文件里，博文顺序看起来是乱的，不是按时间从新到旧。

## 原因

数据库里存的是微博原始英文时间格式：`Wed Sep 30 20:45:17 +0800 2020`。
之前用 SQL 的 `ORDER BY created_at DESC` 排序，但 SQL 对这种英文格式是按
**字母顺序**排（W、T、F...），不是按时间排——所以顺序看起来乱了。

测试数据用的是标准格式 `2023-11-15 06:13:20`，字符串排序正好等于时间排序，
所以测试时没暴露这个问题。真实抓取的数据是英文格式，才露出来。

## 修复

`get_posts()` 读取博文后，在 Python 层解析时间字符串为真实时间戳再排序，
兼容两种格式：

- 微博英文格式：`Wed Sep 30 20:45:17 +0800 2020`
- 标准格式：`2023-11-15 06:13:20`

实测 337 条真实博文，严格从新到旧（2023 → 2016），时间戳单调递减。
