# v1.3.9 · 修复长博文全文没展开

## 问题

导出的博文里，那些需要点「展开全文」的超长微博，正文被截断了，
只有开头一小段 + 「全文」链接，没有拿到完整正文。

## 原因

微博接口返回的长文标志字段名是 `isLongText`，但代码里检查的是 `isLong`
（这个字段不存在），所以长文判断永远为 False，从来没调用过全文接口。

## 修复

长文判断改为同时检查三种标志：

- `isLongText`（微博接口真实字段）
- `isLong`（兼容其他接口变体）
- 正文末尾带「全文」链接

任一命中就调用全文接口展开完整正文。

## 关于数量差异的说明

如果你发现导出数量比微博主页显示的少（比如主页 340 条、导出 337 条），
这是正常现象，不是漏抓：

- 受限微博（仅自己可见、定时公开、分组可见）虽然抓到记录，但正文被微博隐藏
- 主页总数包含**已删除**的微博，抓取只能拿到还存在的

## ⬇️ 下载使用

下载 `weibo-export-v1.3.9-win64.zip` → 解压 → 进入 `极客港微博导出` 文件夹 →
运行里面的 `极客港微博导出.exe`。

> 注意：exe 和 `_internal` 文件夹必须放在一起，解压后整个文件夹一起用。
