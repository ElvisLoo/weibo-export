① 填写 Cookie（推荐）登录态抓全量

  1. 电脑浏览器打开 m.weibo.cn 并登录自己的微博
  2. 按 F12 打开开发者工具 → Network(网络) → 刷新页面
  3. 点任意请求 → Headers → 找到 Request Headers 里的 Cookie
  4. 整行复制，粘贴到下面输入框
🔒 Cookie 等同账号凭证，仅保存在本机内存用于本次抓取，不会上传任何服务器。请勿泄露给他人。

② 抓取博文

在 m.weibo.cn 打开对方主页，地址栏 /u/ 后面的数字即用户 ID
选「模拟」会生成假数据用于验证导出，不触网、不消耗真实请求。
默认 20 秒，新浪限流严格，这是稳定部落实测的安全值
每页约 10 条；先设个小值试跑更稳妥
